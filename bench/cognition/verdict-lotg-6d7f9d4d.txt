## Audit de A (0b234822) — INCOMPATIBLE avec l'arbitrage K/ObservationId
`src/autorite_k.rs` de A définit `AutoriteK { identite: String, compteur: u64 }`
et `emettre() -> String` avec `K = "identite-compteur"`. `identite_fraiche()`
dérive l'identité de `SystemTime::now()` + `std::process::id()` + une séquence
`AtomicU64`. Verdict : K n'est PAS un u128 ; la chaîne n'est pas un simple
encodage ; pid+compteur local n'est pas une preuve d'unicité globale ; le
compteur n'est pas partagé entre processus ; la persistance (`persister`) est un
`std::fs::write` SANS fsync ni atomicité (un second registre, plus faible que
celui de B). L'arbitrage (3ee9a6a9) exige K = u128 compatible ObservationId.

## Audit de B (73a27273→b3ec6b06) — durabilité conforme
`ecrire_durable` établit l'atomicité (temporaire + rename) ET la durabilité
(fsync fichier avant rename, fsync répertoire après), ordre observable via
`ecrire_durable_observe`. `qualifier`/`relire_qualifie` classent tout octet en
Courant / QuarantaineLegacy (V1) / QuarantaineIllisible, préservant octets +
provenance (jamais de refus qui efface). `admissibilite` refuse les corruptions
syntaxiquement valides (K vide/blanc, génération 0, autorité 0). Verdict de B
déjà consigné (54 tests) : préservé, intégré, non remis en cause.

## Correction appliquée (la fusion)
1. K = u128 partout (EnregistrementOriginal.k), encodage 16 octets LE dans le
   record V2 (ENREGISTREMENT_VERSION reste 2 — format expérimental, jamais
   publié). La vue V1 historique conserve sa chaîne (format legacy figé).
2. `AutoriteK` réécrite : compteur u128 monotone (émission depuis 1, 0 = jamais
   émise), persisté via `reconciliation::ecrire_durable` (réutilise la garantie
   de B, pas un second registre), `checked_add` (saturation refusée), état
   corrompu/nul refusé nommément (jamais de réinitialisation silencieuse).
3. `verifier_liaison(record, tentative)` confronte `autorite_consommateur` à
   `tentative.autorite()` (tentative étrangère refusée) et exige `k != 0`.
4. `resoudre_operation` rend la liaison OBLIGATOIRE : aucune transition
   `Attribution::resoudre` sans `verifier_liaison` (les deltas A — l'enum
   `IssueResolutionOperation` et `resoudre_operation` — et B coexistent).
5. `admissibilite` refuse `k == 0` (corruption syntaxiquement valide, jamais
   émise).

## Les huit témoins de A (k_durable_autorite) — verts
1. même opération après redémarrage (K stable, génération/autorité réémises)
2. nouvelle tentative après refus certain (même K, génération incrémentée)
3. ancienne tentative indéterminée (K inchangé)
4. deux opérations indépendantes de contenu identique (K distincts)
5. deux opérations d'une même classe (K distincts)
6. collision de decision_id (K distingue, liaison lie l'autorité)
7. tentative étrangère refusée (même decision_id+génération, autre autorité)
8. corruption valide de K/génération (K nul / génération 99 → liaison refusée)

## Vérifications demandées
- allocation interprocessus : émission séquentielle durable (scénario 4, deux
  processus sur la MÊME autorité K → K distincts). NON mesuré : émission
  CONCURRENTE simultanée (pas de verrou interprocessus sur l'autorité K — limite
  documentée, le modèle opérationnel est « une autorité par store, un écrivain »).
- persistance avant publication : emettre() persiste AVANT de rendre K.
- redémarrage : compteur restauré (ouvrir relit), jamais régénéré.
- copie/restauration : la restauration d'un état corrompu est refusée (pas de
  réinitialisation silencieuse) — non testée : restauration d'une SAUVEGARDE
  antérieure (ré-émission d'un K déjà publié, hors périmètre).
- corruption : état tronqué ou compteur nul → InvalidData nommé.
- saturation : checked_add → erreur nommée (pas de wrap silencieux).
- refus des tentatives étrangères : verifier_liaison confronte tentative.autorite().
- liaison à l'autorité active : resoudre_operation (chemin opérationnel) l'impose.
- récupération des obligations : resoudre_obligation (V1) — non attestée, jamais
  absente définitivement (hérité de B, vert).

## Non mesuré / limites (honnêteté)
- survie à une coupure d'alimentation (fsync = condition nécessaire, pas preuve).
- émission CONCURRENTE simultanée de K (pas de verrou sur l'autorité K).
- ObservationId n'existe pas dans obrain@89d169d7 (PR #418 postérieure) : la
  compatibilité K=u128 est au niveau du TYPE (from_u128/as_u128), non exercée
  contre le type concret.
